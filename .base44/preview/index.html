Neon EQ

System-wide audio equalizer for Android — neon AMOLED UI, 10 presets, 5/10/15/31 bands, native C++ DSP engine.

This is an Android app

Neon EQ runs on an Android phone, so it can't render inside this browser preview — Android apps have no web surface. What you see here is the build environment: it compiles the app from source and hands you the APK.

Install the APK on an Android 8.0+ (API 26+) device to actually use the app.

Install on your phone

  1. Download the APK above (open this page on the phone, or transfer the file).
  2. Allow installing from unknown sources when Android asks.
  3. Open Neon EQ, toggle the EQ on, pick a preset or drag the bands.
  4. Keep the foreground service running so the EQ stays active in other apps.

Rebuild after a code change

docker compose -f docker-compose.base44.yml restart app

The source is mounted into the container, so restarting re-runs the self-test, the unit tests and the APK build against your current code. up -d --build is only needed after changing the compose file or the builder image.
